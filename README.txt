DLS TOURNAMENT HUB

FILES
- index.html: website structure
- style.css: design and mobile layout
- script.js: teams, fixtures, results and automatic standings

HOW TO USE
1. Open index.html in a web browser to test the website.
2. Scroll to Manage tournament.
3. Set your tournament title.
4. Add all teams/players.
5. Create fixtures and add dates/times if known.
6. Use Enter a match result to update a fixture. The standings update automatically.

PUBLISH FREE WITH GITHUB PAGES
1. Open your GitHub repository.
2. Choose Add file > Upload files.
3. Upload index.html, style.css and script.js (you can also upload this README).
4. Commit the files to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose main and /(root), then Save.
8. Wait a short while and open the website link shown on the Pages screen.

IMPORTANT
This version stores changes in the browser/device where they are entered. Visitors on other devices can view the published website, but they will not automatically receive your later edits from your browser. Shared live updates require a database or an admin publishing workflow.
